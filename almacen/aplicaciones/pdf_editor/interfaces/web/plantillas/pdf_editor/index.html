    Extraer texto del PDF

    Si la página es un escaneado, el texto se reconoce con OCR y puede tardar unos segundos. En documentos largos conviene extraer página por página en vez de todas a la vez.
    Elegir área cierra esta ventana para que marques con el ratón la zona que quieras (una tabla, un párrafo, una firma): se lee solo eso y sale tal cual está escrito, con sus renglones y columnas.

    Eliminar páginas

    Indica qué páginas quieres eliminar del documento (tiene 0 páginas).

    Se puede escribir una página (7), varias separadas por comas (3, 8, 15), un rango (5-40) o hasta el final (150-fin). Todo junto también vale: 5-40, 55, 90-120.

    Organizar páginas

    Arrastra las páginas para reordenarlas, o haz clic en una para seleccionarla y muévela con ↑ ↓. Para eliminar: el botón ✕ de la página, doble clic sobre ella, o marca varias y usa "Eliminar seleccionadas". En documentos largos escribe el rango (por ejemplo 5-40, 55, 90-120) en la casilla de abajo y elimínalas de una vez.

    Exportar contenido de texto

    Extrae todo el texto del documento y lo descarga como documento Word (.docx) listo para editar.

    Nota: Esta función extrae texto incrustado digitalmente. Para PDFs escaneados (imágenes), el texto puede estar vacío. El formato Word/Excel/PowerPoint requiere LibreOffice instalado en el servidor.
