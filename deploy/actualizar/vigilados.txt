# Archivos del sistema que vigila maquita-actualizar (deploy/actualizar/lib/vigilados.py).
#
# Antes de aplicar una versión se toman sus sumas sha256 (y una copia del contenido, en el respaldo de la
# actualización); al terminar se comparan y se informa qué se creó, cambió o borró fuera del código.
#
# Formato:
#   [grupo]                       los patrones siguientes forman ese grupo en el informe y en el panel
#   /ruta/con/*/comodines         «*» y «?» dentro de un nombre, «**» cualquier número de carpetas,
#                                 {a,b} alternativas
#   /ruta  deploy/origen          segunda columna: el archivo del repositorio que el producto instala tal
#                                 cual en esa ruta. Sirve para detectar parches locales: si el archivo
#                                 instalado no es igual al del repositorio en la versión anterior, «tenía
#                                 cambios locales». Si termina en «/», se le añade el nombre del archivo;
#                                 si lleva un «*», toma lo que el «*» de la ruta abarcó. Solo para copias
#                                 literales (no para archivos que el instalador arma o retoca).
#   !/patrón                      excluido (vale para todos los grupos)
#
# Los enlaces simbólicos no se siguen: se vigila a dónde apuntan.
